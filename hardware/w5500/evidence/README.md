# W5500 physical evidence

No physical evidence has been collected yet. Timestamped qualification logs,
PCAPs, sigrok sessions, scope screenshots, wiring photographs, kernel config,
and tool versions belong here after the hardware is connected.

Do not copy XNIC QEMU evidence into this directory or describe it as board
validation.

`software/` contains the separately labelled ARM64 build/sparse result, pure
contract-model tests, DT overlay build, and unbound module lifecycle smoke test.
They reduce software risk but are not a substitute for any physical gate.
